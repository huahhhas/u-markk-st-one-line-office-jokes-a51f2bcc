# One-Line Office Jokes

A [make.fun](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc) bounty entry: a Python program that deterministically writes one single-line joke about office life (under 200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

The joke turns on a real detail of office life — the printer that only jams on urgent documents — and lands its laugh in the last few words.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

## Entry

> The printer only jams on urgent documents, so I keep a printed resignation letter in my drawer — in case it ever decides to work.
